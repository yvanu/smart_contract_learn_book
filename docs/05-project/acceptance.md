# 05-3 自动化测试与项目验收

## 本地验收命令

```bash
cd examples/foundry
forge build
forge test -vv
forge test --match-contract EscrowTest -vvvv
forge test --gas-report
```

## 最小验收矩阵

| 编号 | 情况 | 期望 |
| --- | --- | --- |
| A01 | 买家创建合约且初始付款 | Funded、余额匹配 |
| A02 | 卖家交付、买家放款 | Released、卖家收到 ETH |
| A03 | 未交付直接放款 | revert InvalidState |
| A04 | 陌生人交付/放款 | revert Unauthorized |
| A05 | 截止前退款 | revert TooEarly |
| A06 | 截止时间及之后退款 | Refunded、买家收到 ETH |
| A07 | 退款后再次结算 | revert InvalidState |
| A08 | 部署时 0 余额或错误地址 | revert |
| A09 | 买家和卖家身份相同 | revert |
| A10 | Fuzz 截止时间后的合法退款 | 任意有效时间都能退款 |

## 安全审阅问题

1. 谁有权操作托管？能不能通过转发合约欺骗身份？
2. 一笔订单能否收款两次？
3. 资金是否因卖家回退收款而永远停住？（可能；已明确为风险）
4. 这份代码是否可以升级？（不能；是单独部署的新实例）
5. 买家恶意拒绝确认交付怎么办？（可到期退款；现实商业争议需要仲裁）
6. 买家已经收到货但到期仍退款怎么办？（教程不解决线下履约欺诈）

## 发布门禁

| 门禁 | 本教程要求 |
| --- | --- |
| 使用测试网 | 是 |
| 本地单测 | 必须全通过 |
| 模糊测试与边界 | 至少 2 类 |
| 专业审计 | 未完成，不可声明已审计 |
| 真实资金托管 | 禁止用于生产 |
| 余额、资金与状态记录 | 必须能从交易回执复核 |

通过本地验收后，可以阅读 [下一阶段](/06-career/) 的测试网部署与审计路线。
