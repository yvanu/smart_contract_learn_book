# 学习验收清单

## 第 1 阶段：能独立写合约（第 1–4 周）

- [ ] 区分 EOA、合约账户、私钥、签名、公钥/地址
- [ ] 用自己的话解释交易、区块、Gas、nonce 与链 ID
- [ ] 在 Remix 编译并部署 Counter（仅 Remix VM）
- [ ] 分清 `storage`、`memory`、`calldata`
- [ ] 能解释 `msg.sender` 和 `tx.origin` 的区别
- [ ] 能正确设计权限检查、事件、revert

**验收:** 自己修改 Counter 加一个 owner-only reset，非 owner 调用必须失败。

## 第 2 阶段：能给合约写测试（第 5–8 周）

- [ ] Foundry 工程能在离线本地 EVM 执行测试
- [ ] 编写 `expectRevert` 和不同调用者角色的测试
- [ ] 能说明一个重入风险和 CEI 的适用边界
- [ ] 有至少两个模糊测试来覆盖状态/参数边界
- [ ] 理解 ERC-20 allowance、标准接口和非标准返回值风险

**验收:** 编写一个失败用例，证明未授权调用无法转走项目托管的以太币。

## 第 3 阶段：项目交付（第 9–12 周）

- [ ] 画出 Escrow 角色和状态转移图
- [ ] 实现创建、资金锁定、确认、释放、超时退款
- [ ] 列出至少 5 个不变量和反例
- [ ] 单元测试成功路径、失败路径、超时边界
- [ ] 记录合约地址/网络/源码哈希（仅测试网）
- [ ] README 写清风险假设、测试命令和局限

**验收:** 不看教程，用 5 分钟演示流程，再用 5 分钟说明哪些情况仍然有风险。
