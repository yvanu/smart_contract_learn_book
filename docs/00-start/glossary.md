# 零基础术语词典：看不懂就回来查

> 这页不是要求你背诵的单词表。**第一次看到一个术语，不懂就回来查；能用自己的话解释就够了。** 按学习顺序排，不按英文字母排。

## 第一组：最先遇到的 12 个词

| 术语 | 一句话白话解释 | 你熟悉的类比 |
| --- | --- | --- |
| 区块链 Blockchain | 多台计算机按照协议共同维护可验证的状态和交易记录 | 多方共同维护的账本，不是单台 MySQL |
| 智能合约 Smart Contract | 部署到区块链，由网络规则执行的程序 | 放在链上的业务模块 |
| Ethereum / 以太坊 | 支持智能合约的一条区块链生态/网络 | 不是一个具体 APP |
| EVM | 执行合约字节码的虚拟机 | 有点像 Python 运行时，但有 Gas 和确定性规则 |
| Solidity | 常用于编写 EVM 智能合约的语言 | 类似你用 Python 写后端 |
| 地址 Address | 标识账户或合约的公开编号 | 账号，但不等于真实身份 |
| 私钥 Private Key | 授权交易的关键秘密材料 | 比密码更危险：泄露就可能失去资产控制 |
| 助记词 Seed Phrase | 一种用于恢复钱包密钥的词语序列 | 极其敏感的恢复材料 |
| 钱包 Wallet | 管理密钥、显示状态、发起签名的工具 | 用户端签名器，不是余额文件夹 |
| 交易 Transaction / Tx | 向区块链提交的状态变更请求 | 有签名、有执行结果的写入操作 |
| RPC / Node | 查询区块链并提交交易的接口/节点 | 类似应用访问远程 API |
| Gas | 为 EVM 操作计量的执行资源 | 不是 ETH 本身，类似资源计量 |

| 术语 | 白话解释 | 例子 |

| contract | 一份合约声明 | `contract Counter` |
| state / 状态 | 合约保存的当前数据 | `number` 现在是 2 |

| mapping | 按键取值的存储结构 | 地址 → 余额 |

## 容易混淆的三组概念

### 地址、钱包、余额

地址是链上标识；钱包是帮助你管理密钥的软件/硬件；余额是链上的数据。**卸载钱包软件不等于清空链上余额**，但丢失恢复材料可能导致无法控制账户。

### Gas、ETH、手续费

Gas 是计算资源单位；ETH 是以太坊原生资产；网络交易费用在以太坊主网通常用 ETH 支付。**Gas Used × Effective Gas Price** 可用于理解执行费用，但 L2 可能还有其他收费项目。

### 合约源码、ABI、合约地址

源码是你写的 Solidity；ABI 是调用接口描述；合约地址是一个已部署实例的地址。**有源码不代表已部署，有地址不代表你拥有源代码**。

## 读不懂时怎么做

回到你正在读的章节，只问三件事：

1. **这个东西是什么？** 用上面的一句话翻译。
2. **谁在什么时候用它？** 例如钱包在“签名交易”时使用私钥。
3. **我能在哪里看到它？** 例如在 Remix 的账户列表看到地址，在终端看到 Gas Used。
